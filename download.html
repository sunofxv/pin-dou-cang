🤖 安卓

可安装的 APK，由 GitHub Actions 自动构建（需 Android 5.1+，安装时允许「未知来源」）。首次构建约几分钟，完成后即可直接下载安装到手机。

下载安卓版 (.apk)

📱 iPhone / iPad

iOS 无法直接安装安装包，但可以把当前页面保存到桌面，像 App 一样使用：

  1. 用 Safari 打开本页面（或 pindoucang.online）
  2. 点击底部「分享」按钮
  3. 选择「添加到主屏幕」，即可把当前页面保存到桌面
  4. 桌面出现「拼豆豆仓」图标，点开即用
